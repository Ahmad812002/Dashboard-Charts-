# 📊 Dashboard Charts

An interactive data visualization dashboard built with React.js.  
Displays multiple datasets using different chart types, each styled 
independently — plus full dark mode support.

## Features
- Multiple chart types for different data categories
  (bar charts, line charts, pie charts)
- Each chart section has its own unique visual style
- 🌙 Dark mode / Light mode toggle
- Fully responsive layout

## Tech Stack
| Layer      | Technology      |
|------------|-----------------|
| Framework  | React.js        |
| Styling    | CSS             |
| Markup     | HTML            |

## 🏁 Getting Started
1. Clone the repository
2. npm install
3. npm start
4. Open http://localhost:3000
5. in another terminal run cd data
6. then run npx json-server --watch db.json --port 8000
